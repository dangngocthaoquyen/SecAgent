## 5. Promptfoo comparison boundary

The described Promptfoo ToolBot provider sends a **user prompt to a DeepSeek assistant** that may choose MCP tools. The present SecAgent canary sends a **preselected `tools/call` directly from SecAgent to the ToolBot tool service**. These do not test the same actor or decision boundary: the SecAgent case has no matching user prompt/legitimate task, no Agent-selected tool decision, `execution_action` at tool-service attribution, and only partial target-reported evidence at 7010. Promptfoo's assistant transcript and any grader output are not equivalent to a correlated handler receipt or sandbox effect. Therefore **do not compare detection rates directly** or pool denominators.

A valid later comparison must pre-register one common target revision, model/assistant orchestration, legitimate task, attack objective, payload, response capture, evaluation scope and evidence contract for both systems. If those cannot be made identical without an adapter, report **two separate arms**: (1) response-level Agent behavior with paired prompts and human-adjudicated captured responses; (2) SecAgent direct MCP tool-service evidence as a separate capability pilot. Existing ASI05 CodeBot response-based results may inform a carefully matched response-scope design, but cannot be merged with ToolBot direct-action results. This is a methodological proposal, not a new result.
